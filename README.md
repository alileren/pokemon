# Bot Pokemon

### About this bot

This bot was made at Python Level 3 class in **Kodland**. We learned about OOP
and try to implement the OOP _inside_ this bot.

![Pikachu](https://static.wikia.nocookie.net/pokemon/images/4/49/Ash_Pikachu.png/revision/latest/scale-to-width-down/1000?cb=20200405125039)

### How to try

1. Clone this repo
2. Obtain a token from [Dicord developer site](https://discord.com/developers/applications).
3. Make a `config.py` and insert a variable `token` and assign your token to this variable.
4. Run
   ```shell
   python main.py
   ```
